# Ritim

A cycle-tracking and mental wellness app for teenage girls, designed with a supportive, judgment-free approach to help them understand their bodies and emotions.

## Background

Built after observing a real gap: most cycle-tracking apps are designed for adult women and don't speak to the emotional and educational needs of teenage girls. Ritim is my own solution to that gap — a space that's approachable, age-appropriate, and genuinely supportive rather than purely clinical.

## Architecture

- **Backend**: Supabase up to a certain user scale, with a planned migration to a self-managed VPS running PostgreSQL as the user base grows
- **Frontend**: Flutter (Dart)

## Status

Actively in development, not yet launched. This is an ongoing project with a clear growth roadmap — the current focus is scaling the backend architecture to support the app beyond its early user base.

## Roadmap

Actively planning the next phase of features and the production infrastructure needed to support growth beyond the initial Supabase setup.
